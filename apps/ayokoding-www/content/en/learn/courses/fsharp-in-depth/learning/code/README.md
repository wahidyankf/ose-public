## Example code for fsharp-in-depth

One folder per worked example: `ex-NN-<slug>/` holds `main.fsx`, its `run.yaml` (`toolchain: dotnet`, pinned .NET 10.0.402 SDK, no network), any fixture files the script reads, and the recorded output under `expected/`. Every unit is standard library only, so no lockfile exists and no `dependencies.lockfile` entry appears in any `run.yaml`.

Every unit is deterministic: fixtures are committed beside the script, no clock is ever read, case tables are generated by fixed formulas, concurrency demos rendezvous on reply channels with sorted transcripts, thread identifiers are never printed, and printed values are constructed by the script. Scratch writes go to fixed paths under /tmp with fixed content and are deleted before exit. Standard output is the asserted golden transcript; standard error is ignored, which matters for the offline workload-verification note the container runtime logs there by design.
