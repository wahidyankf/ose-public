This course teaches Hermes Agent the way an engineer actually drives it from a terminal: configuration, prompting discipline, permission scoping, trace reading, and failure recovery. It mirrors the sibling agent-tool courses in this plan on purpose, so skills transfer and comparisons stay fair.

Start with the [learning overview](./learning/overview.md), work the examples in order, and use [drilling](./drilling/overview.md) to check what you can explain and repair without a model answer. The [capstone](./learning/capstone/overview.md) drives one realistic multi-step repository task end to end.

Every runnable example drives a deterministic fixture shim of Hermes Agent, not the live product: no real network call, no real API key, no real account. Where the shim simplifies the vendor's behavior, the example says so, and version-specific facts carry their access date in the learning overview's References section.

The course is a practical starting point for daily terminal-agent work. It does not reproduce the vendor's own onboarding tutorial, and anything that only a live account could prove is out of scope by design.
