This primer teaches the Python you need to read, write, and test small programs: values and
collections, control flow, functions, modules, file and JSON handling, exceptions, type hints, and
command-line tools. It assumes basic terminal use and no prior Python knowledge.

Start with the [learning overview](./learning/overview.md), work through the examples in order, and
use [drilling](./drilling/overview.md) to check what you can explain and repair without a model
answer. The [capstone](./learning/capstone/overview.md) combines a typed JSON transformation with a
command-line entry point and tests.

The course is a practical starting point. It does not teach asynchronous programs, packaging for
publication, or the full object model. Those topics require more than a primer can demonstrate
honestly.
