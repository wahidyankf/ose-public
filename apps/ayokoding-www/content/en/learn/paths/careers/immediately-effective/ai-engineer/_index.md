This path is for developers who already write software. The "Before you start" list shows the courses it assumes; take any you have not covered first. The path then moves from computing basics and shipping software to building with models, agents, evaluation, and serving and adapting models.

The sequence is practical: learn to observe and test a system before relying on it, and treat deployment, evaluation, and adaptation as one engineering discipline.

Course pages you open from this path keep the path context, so Previous and Next follow this path.
