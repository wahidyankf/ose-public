# Syllabus Courses — Accounting

One file per course. Each file follows the
[copy-paste course template](../../../../../repo-governance/conventions/structure/learning-plan-syllabus/copy-paste-course-template.md)
and adds four plan-specific sections the executor needs:

- `## Mode and targets` — the teaching mode, the reason for it, and the measurable targets.
- `## Learning objectives` — what a reader can do after the course.
- `## Drilling` — the drill sections and the named code katas.
- `## Code and harness` — the code medium and anything special the harness must run.

The shared targets behind every `## Mode and targets` section, and how they were derived, are in
[tech-docs/002](../../tech-docs/002-course-modes-and-definition-of-done.md). The code rules are in
[tech-docs/003](../../tech-docs/003-code-harness-and-determinism.md), and the Sharia content rules in
[tech-docs/004](../../tech-docs/004-sharia-content-policy-and-sources.md).
