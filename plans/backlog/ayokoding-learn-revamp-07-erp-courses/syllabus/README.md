# Syllabus — ERP Courses and Paths

**Custodian**: ayokoding-learn-revamp-07-erp-courses

This corpus specifies the 30 ERP courses and the two ERP skills paths that plan 07 delivers. It is the contract the maker agents follow: each course file fixes the course's mode and reason, learning objectives, concepts, worked-example cluster plan with named anchor examples, capstone, drilling, runtime, and checks. Slice S0 of each course's authoring expands the example list to every example before the pages are written.

| Folder                          | What it holds                                                                   |
| ------------------------------- | ------------------------------------------------------------------------------- |
| [courses/](./courses/README.md) | One file per course, in path order (30 files)                                   |
| [paths/](./paths/README.md)     | The two ERP skills manifests with final JSON, page copy, and closure derivation |

## Scope

- 30 courses: 27 conventional ERP courses and 3 Sharia ERP courses. 18 are By Example and 12 are Annotated-Concept; none uses the primer, in-the-field, or no-code modes (reasons in the technical design).
- The accounting prerequisites (7 courses) belong to the accounting plan and are outside this corpus.
- Course bodies, code, and drilling are written during execution, not in this corpus.

## Corpus Rules

- The syllabus keeps the `## Accuracy notes` heading the syllabus template requires. The published course pages use `## References` instead (series decision 24).
- Archived predecessors in `plans/done/2026-08-16__ayokoding-learning-path-17-skills-erp-foundations/` and `plans/done/2026-08-16__ayokoding-learning-path-18-skills-erp-enterprise-depth/` are history only and are never edited.
- This corpus archives with the plan (`archive-with-plan`); no consumer outside `plans/` reads it.
