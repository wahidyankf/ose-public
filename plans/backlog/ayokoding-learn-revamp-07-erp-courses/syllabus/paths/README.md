## Skills Paths Input From Plan 02

Plan 02 drafted these phases as input and left their application to this plan (decision 39). This plan keeps plan 02's phase boundaries and outcome wording, because the finished course set matches the draft: the same 27 and 30 courses in the same order. The outside prerequisites match too, with one addition: `just-enough-python` joins `assumes`, because plan 02's prerequisite rubric rule L1 makes a language primer a prerequisite when that language is the course's primary code medium, and every finished ERP example is written in Python 3.14. Plan 02 left the rubric re-run for outline courses to the plans that rewrite them. The drafts it consumed are read-only:
