command-execution-note
- The session runs behind a worktree-isolation guard. The user-level `rtk hook claude` PreToolUse hook rewrites every

  prove where the wrapped command runs. Every git command in this plan was therefore executed as the plain command
  `RTK_DISABLED=1 git ...` from this worktree (the documented per-command rtk opt-out), which the guard accepts. The
  command text recorded in this plan keeps its literal `rtk git ...` form; only the invocation differs.
