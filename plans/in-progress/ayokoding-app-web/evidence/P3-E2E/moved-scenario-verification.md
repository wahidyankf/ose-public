# P3-E2E moved-scenario verification against the real corpus

Witnesses were found by rule in `apps/ayokoding-www/content` and `apps/ayokoding-www/src/redirects`. No title was
copied from the fixture to choose a witness. This file is the be witness list that `P3-Corpus` uses.

Two fields per row:

- **Precondition**: `real corpus` when the scenario's data exists in the real corpus, `fixture only` when it cannot.
- **Witness**: the real file or rule that supplies the data.

Where a scenario's literal assertion text names fixture content (for example `go-basics/learning/hello-world` or
`Legacy Software Engineering`), the real witness is recorded here and the literal is a rewrite for `P3-Corpus`. P3-E2E
changes no assertion text.
