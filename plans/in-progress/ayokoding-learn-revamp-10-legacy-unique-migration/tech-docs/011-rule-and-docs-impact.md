## Summary

This plan's rule and docs footprint is deliberately narrow: it adds course content, one new toolchain
definition (WebAssembly), install-recipe extensions to the merged `clojure` and `kotlin` entries, test
extensions, and plan documents; it edits no repository rule and no `docs/` file. Every
edit outside `apps/ayokoding-www/content/en/learn/courses/` and `apps/ayokoding-cli/toolchains/` is a test
or spec file extension, listed exhaustively in [tech-docs/010](./010-file-impact.md).
