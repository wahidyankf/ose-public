# By-Example Tutorial Convention

## Purpose

This convention **extends the [Tutorials Convention](../tutorials/general.md) for the By Example tutorial type**, defining specialized standards for code-first learning through 75-85 heavily annotated, self-contained, runnable examples achieving 95% coverage. Target audience: experienced developers switching languages/frameworks who prefer working code over narrative. Full standard split into the chapters below.
