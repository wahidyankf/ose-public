# Behaviour-Driven Development Details

- [BDD Coverage, Exemptions, and Execution](./coverage-exemptions-and-execution.md) — Static coverage targets, higher-layer exemptions, test:quick composition, and runtime execution surfaces. Use when defining BDD coverage targets, documenting an Integration/E2E exemption, or selecting a runtime execution surface.
- [Script-Subject Unit Proof](./script-subject-unit-proof.md) — What Unit means when a scenario's production subject is a shell script or a harness plugin file run by its host runtime: direct execution with every collaborator faked, a private home, no network, bounded time, and assertions on the subject's own contract. Use when binding or reviewing such a Unit row.
