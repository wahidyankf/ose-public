# Task List Discipline

- [Task List Discipline — Purpose and Scope](./purpose-and-scope.md) — The two failure modes (lost context, invisible drift) a live task list prevents, and why the practice carries no step-count threshold Use when deciding how this practice reaches a specific piece of work.
- [Task List Discipline — Standards 1-5](./standards-1-to-5.md) — Create the list before starting, mark in-progress before starting a task, mark completed immediately after verification, add discovered tasks on the spot, and one task per concrete outcome Use when creating or updating task entries during multi-step execution.
- [Task List Discipline — Standard 6: Idle-Polling Status Heartbeat](./standard-6.md) — The five-minute heartbeat required only while the main thread has no useful work beyond polling a non-CI background agent or process. Use when the main thread becomes idle while external work continues.
- [Task List Discipline — Standard 7: Continuation State](./standard-7-continuation-state.md) — Preserve active user-established repository-rule decisions across compaction and handoff, then reconcile them with canonical instructions before resuming. Use when recording a user-set rule or restoring compacted or handed-off work.
- [Task List Discipline — Standard 8: Reconcile the List When New Direction Arrives](./standard-8-new-direction.md) — New, follow-on, or changed direction reconciles against every open item before any work responds to it. Use when the user supplies a new instruction, a follow-up, or a correction while a list is already open.
- [Task List Discipline — Anti-Patterns](./anti-patterns.md) — Five common task-list failure patterns - starting without a list, marking done before verifying, deferred cleanup, recording discovered work without adding it, and monolithic tasks Use when reviewing your own task-list behaviour for signs of one of these five failure patterns.
- [Task List Discipline — For AI Agents and Related Documentation](./for-ai-agents-and-related-documentation.md) — The five-point checklist for AI agents doing qualifying multi-step work, its relationship to plan delivery checklists, the outside-plan progress file, and links to related documentation Use as a quick-reference checklist before starting qualifying multi-step work, or to find related conventions and principles.
