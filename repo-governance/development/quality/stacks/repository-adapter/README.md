# Repository Adapter Modules

- [Adopter Decisions](adopter-decisions.md) — Each open choice from an adopted standard, and each local rule stronger
  than the catalog, with its reason. Use when a standard asks for an adopter decision or a local rule tightens one.
- [Project Applicability](project-applicability.md) — Links each inventory project to its README, carries the facts of
  projects without one, and names the version manifests. Use when locating a project's stacks, commands, or versions.
