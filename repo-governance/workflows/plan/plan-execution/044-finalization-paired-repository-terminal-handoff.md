# Paired-Repository Terminal Handoff

After the source merge, prove its merge SHA reachable from source `origin/main`. Create and open the
successor PR, then capture its exact repository, PR number, initial head, destination-base SHA, and
branch before any successor scout runs. Admit all existing source-PR `IssueComment` objects first.
Reuse one valid handoff; stop on any invalid or conflicting admitted record. Only when none exists,
post exactly one top-level comment on the merged source PR using the
[`ose-pr-review-sibling-handoff:v1` schema](../../../development/quality/pr-review-disciplines/sibling-handoff-record.md):

```bash
HANDOFF_JSON="$(jq -cn \
  --arg source_repository "$SOURCE_REPOSITORY" \
  --argjson source_pr "$SOURCE_PR" \
  --arg source_final_reviewed_head "$SOURCE_FINAL_REVIEWED_HEAD" \
  --arg source_merge_sha "$SOURCE_MERGE_SHA" \
  --arg successor_repository "$SUCCESSOR_REPOSITORY" \
  --argjson successor_pr "$SUCCESSOR_PR" \
  --arg successor_initial_head "$SUCCESSOR_INITIAL_HEAD" \
  --arg successor_base_sha "$SUCCESSOR_BASE_SHA" \
  --arg successor_branch "$SUCCESSOR_BRANCH" \
  '{source_repository:$source_repository,source_pr:$source_pr,
    source_final_reviewed_head:$source_final_reviewed_head,source_merge_sha:$source_merge_sha,
    successor_repository:$successor_repository,successor_pr:$successor_pr,
    successor_initial_head:$successor_initial_head,successor_base_sha:$successor_base_sha,
    successor_branch:$successor_branch}')"
HANDOFF_BODY="$(printf '<!-- ose-pr-review-sibling-handoff:v1\n%s\n-->\n\n---\nGenerated by AI' "$HANDOFF_JSON")"
POSTED_HANDOFF="$(gh api --method POST \
  "repos/${SOURCE_REPOSITORY}/issues/${SOURCE_PR}/comments" -f body="$HANDOFF_BODY")"
HANDOFF_COMMENT_ID="$(printf '%s' "$POSTED_HANDOFF" | jq -r '.id')"
gh api "repos/${SOURCE_REPOSITORY}/issues/comments/${HANDOFF_COMMENT_ID}"
```

Immediately run the canonical
[typed read-back](../../../development/quality/pr-review-disciplines/sibling-handoff-record.md#typed-read-back-and-freeze),
including the paginated uniqueness check. Freeze the successor until that exact returned comment
and every immutable source/successor coordinate authenticate. Emission failure or an ambiguous
retry never authorizes a second post.
