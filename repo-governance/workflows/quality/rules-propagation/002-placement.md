# Placement

## Who Must Read It

| Audience                           | Destination                                                               |
| ---------------------------------- | ------------------------------------------------------------------------- |
| everyone, before opening any file  | a candidate for the root instruction file                                 |
| everyone, on reaching one activity | the governance level answering the rule's question, per Governance Layers |
| one delegated agent                | that agent's definition or skill                                          |
| a machine only                     | a declaration, not prose                                                  |

Record the level even for a root-file candidate, so a failed admission lands there without deriving it again.

## Admission to the Root Instruction File

Admit a candidate only when both conditions hold, judged in this order:

1. **Necessity.** It changes behaviour before any file is opened. A contributor who would reach the rule through the
   activity it governs is served as well by a governance document, at no budget cost.
2. **Room.** The file has headroom for it, or a relocation frees enough.

Room never rescues a rule that fails necessity; otherwise the root file fills with rules a link would have delivered. A
vendor-neutral rule goes in the canonical root file, never in a harness-specific one, where it would bind one harness
while looking landed. Vendor-specific text follows
[Vendor-Neutral Governance](../../../conventions/structure/governance-vendor-independence.md).

## Otherwise, the Owning Document

A rule not admitted joins the document that already owns its subject, at the level recorded for it. A new document is
created only when none owns the subject, and it is indexed like any other. A rule appended to an unrelated document is a
rule nobody finds.

## Making Room

Ceilings are fixed, per [Document Word Budget](../../../conventions/structure/governance-word-budget.md): no raise,
exemption, or ignore entry pays for a placement.

When an admitted rule finds no room, rank the file's current entries by the same necessity test and relocate the
weakest, never the oldest or the last. A weak entry points to a fuller statement elsewhere, describes rather than binds,
or has an owning document a reader would try first.

Relocation moves the substance to its owner and leaves at most a link. Deleting an entry outright is allowed only when
it was already superseded, and it is then recorded as a supersession. Compressing an entry in place counts only when the
shorter form still states the whole obligation.

The relocation lands in the same change as the admission, because a deferred one leaves the file over its ceiling.
Measure the result rather than predicting it, including any harness file that shares the root file's ceiling, and record
what moved, where it went, and which admission it paid for.
