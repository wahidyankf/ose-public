# Roots

Specifications for the Roots product family. The family ships one logical owner today —
`roots-be`, a Sharia-compliance API that any consumer can call, independent of the OSE
Application's GRC surface.

The family is named **Roots** because it is meant to hold what Islamic practice grows from —
prayer times, qibla direction, the Islamic calendar, and the compliance judgements that rest
on them. Consumers branch off it; the shared ground stays here.
